# Electricity-Consumption-Analysis
Electricity Consumption Analysis using Python and Power BI.

Electricity Consumption Analysis

About the Project

This project analyses household electricity consumption and electricity bills to understand monthly usage patterns.

Technologies Used

- Microsoft Excel
- Python
- Power BI

Objectives

- Analyse household electricity consumption.
- Calculate monthly electricity bills.
- Identify high electricity usage.
- Create an interactive dashboard.

Project Features

- Monthly electricity consumption analysis
- Electricity bill analysis
- Charts and visualizations
- Interactive Power BI dashboard

Files Included

- Dataset
- Python analysis notebook
- Power BI dashboard
- Project screenshots

Conclusion

This project helps users understand electricity usage patterns and identify opportunities to save electricity.
